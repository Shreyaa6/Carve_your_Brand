# Carve Your Brand - Agency Website

A modern, professional agency website built with React, TypeScript, and Tailwind CSS. Showcasing web development, mobile app development, AI chatbots, and comprehensive web solutions.

## Features

- 🎨 **Modern Design** - Clean, professional design inspired by leading agencies
- 📱 **Fully Responsive** - Works seamlessly on all devices
- ⚡ **Fast Performance** - Built with Vite for optimal performance
- 🎭 **Smooth Animations** - Framer Motion for engaging interactions
- 🎯 **SEO Friendly** - Optimized structure and meta tags
- 🚀 **TypeScript** - Type-safe development

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations
- **React Router** - Navigation

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The production build will be in the `dist` folder.

## Customization

### Update Projects

Edit `src/components/Projects.tsx` to replace the placeholder projects with your actual projects. Update:
- Project titles and descriptions
- Project images (replace Unsplash URLs with your images)
- Results/metrics
- Categories

### Update Contact Information

Edit `src/components/Contact.tsx` and `src/components/Footer.tsx` to update:
- Email address
- Phone number
- Company information

### Update Services

Edit `src/components/Services.tsx` to customize your service offerings.

### Update Stats

Edit `src/components/About.tsx` to update your company statistics.

### Colors & Branding

Modify `tailwind.config.js` to customize the color scheme and branding.
